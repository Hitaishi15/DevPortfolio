# DevPortfolio - Aurelia

A modern, responsive portfolio website showcasing web development skills and projects(JUST AN ANOTHER **PROJECT** NOT A REAL PORTFOLIO).

## Project Description

This is a professional portfolio website for Aurelia, a Full-Stack Developer and UI/UX Designer. The site features a clean, modern design with smooth animations and interactive elements.

## Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Dark Mode**: Toggle between light and dark themes
- **Smooth Scrolling**: Implemented with Lenis for buttery smooth navigation
- **Interactive Projects**: Filterable project gallery with categories
- **Contact Form**: Functional contact form with validation
- **Modern UI**: Clean interface with custom typography (Delius font)

## Technologies Used

- HTML5
- CSS3 (with CSS custom properties)
- JavaScript (Vanilla)
- Lenis (Smooth Scroll Library)
- Google Fonts (Delius)

## Sections

1. **Hero**: Introduction with animated typing effect
2. **About**: Personal background and expertise
3. **Skills**: Technical proficiencies with progress bars
4. **Projects**: Featured work including:
   - E-Commerce Platform
   - Task Management App
   - UI Design System
   - Analytics Dashboard
5. **Experience**: Professional timeline
6. **Contact**: Contact form and information

## How to Run

Simply open `index.html` in your web browser or use the command:
```
start index.html
```
